# latency-test

Измеряет скорость скачивания по URL. Скрипт делает 10 запросов последовательно, считает среднее время запроса и общий объём скачанных данных и показывает скорость.

## Запуск

Нужен Node.js 18+. Зависимостей нет.

```sh
node index.js <url>
```

Пример:

```sh
node index.js https://picsum.photos/id/237/1200/800
```

Вывод выглядит так: `Скорость: 2.41 МБ/с`.

## Примечания

- Единица скорости фиксированная: МБ/с (мегабайты в секунду), округление до 2 знаков. Очень низкая скорость отобразится как `0.00 МБ/с`.
- Измеряемое время включает установку соединения и ожидание ответа сервера, поэтому на маленьких файлах скорость будет ниже реальной пропускной способности. Для реалистичного результата используйте большой файл.
- Количество запросов задаётся константой `REQUESTS` в `constants.js`.
